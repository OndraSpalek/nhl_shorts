V8.1.0 – samostatný sběr YouTube Analytics, bez změny generátoru.
Nahraj čtyři soubory včetně workflow do původních cest. Spusť Actions > Be6player YouTube Analytics V8.1.0 > Run workflow > fixture.
Pro live: v Google Cloud povol YouTube Data API v3 a YouTube Analytics API, vytvoř OAuth klienta a autorizuj vlastní kanál s rozsahy https://www.googleapis.com/auth/youtube.readonly a https://www.googleapis.com/auth/yt-analytics.readonly, offline access. Refresh token získej například OAuth Playground s vlastním klientem a odpovídajícím redirect URI. Ulož YT_CLIENT_ID, YT_CLIENT_SECRET, YT_REFRESH_TOKEN do GitHub Actions Secrets. Nikdy je nevkládej do souborů. U externí aplikace v režimu Testing může refresh token vypršet za 7 dní.
Po ruční publikaci přidej do youtube_registry.json položku např. [{"video_id":"abcdefghijk","published_date":"2026-11-27"}] (nahraď skutečnými hodnotami; datum dle YouTube Analytics, pacifické časové pásmo). Prázdný seznam je platný, ale nic nesbírá.
Live běží denně 12:30 UTC, data do včerejška; API může mít zpoždění. Chybějící report není nula. Chyby jednotlivých reportů jsou v status.json; žádné tokeny se nezapisují. Cache není trvalá záloha, pravidelně stahuj artefakt analytics.db. Statistiky jsou soukromé: používej soukromý repozitář, artefakty/cache mohou být přístupné osobám s přístupem k repozitáři. Pokud je veřejný, live nespouštěj.
Fixture je oddělený od živé cache. V8.1.0 zatím nepáruje časování karet s retencí, neoptimalizuje a neposílá e-mail. Živé API nebylo ověřeno.
